# Contributing to 0GP Race

Thank you for your interest in improving 0GP Race.

The project is currently in active development and community feedback is highly appreciated.

---

## Reporting Bugs

When reporting a bug, please include:

- Plugin version
- RuneLite version
- Operating System
- Description of the issue
- Expected behaviour
- Steps to reproduce
- Screenshots or video if possible

---

## Feature Requests

Feature suggestions are welcome.

Please explain:

- What problem it solves
- How you think it should work
- Any OSRS mechanics involved

---

## Pull Requests

Pull requests are welcome.

Please ensure:

- Code compiles successfully
- Existing functionality is not broken
- New features are tested where possible
- Documentation is updated if required

---

## Code Style

Please follow the existing project style and keep commits focused on a single feature or fix where possible.

---

## Thank You

Every suggestion, bug report and contribution helps improve 0GP Race for the entire Old School RuneScape community.
